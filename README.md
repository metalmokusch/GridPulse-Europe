# GridPulse Europe

A self-hosted dashboard for comparing European electricity generation mixes with clear source, time, unit, freshness, and data-quality information. Runtime AI is not part of the product.

## Status

Project planning and source validation. No application code, live data integration, or provider credentials are present yet.

## Start here

- [Project plan and current blockers](docs/PROJECT_PLAN.md)
- [Initial stack decision record](docs/adr/0001-initial-technical-direction.md)

The intended MVP is a demo-first, read-only application that can run without an API token. Live ENTSO-E ingestion is gated on validating access, zone coverage, data behavior, and reuse terms.
